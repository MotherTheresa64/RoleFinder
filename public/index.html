Personal tool. Postings and links are public, but the ranking is tuned to one profile — so it is not optimized for anyone else. Refreshed daily at 06:17 UTC.

This is one person's job search tool

The postings are real, and every link goes to the company's own application page. What is not generic is the order: scoring is tuned to a single stack — React, TypeScript, Python, FastAPI, PostgreSQL — so the top of this list is that person's best fit, not necessarily yours.

Listings are re-pulled from 33 company boards every day at 06:17 UTC, so a job that closes drops off on the next refresh.

Application status you set here (applied, interview, rejected) is saved in this browser only. It will not follow you to another device, it is not shared with anyone, and clearing site data resets it. Jobs you mark applied drop out of the list so they don't tempt a second application.
